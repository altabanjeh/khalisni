## 4. Established facts (repository intent, one-paragraph)

Khalsni / خلصني is an Arabic-first (RTL) service-request management platform for Jordanian government and administrative services, built as **Django 5 + DRF** (15 apps) + **React 19 + Vite + Tailwind** SPA, with a companion **Expo/React Native** mobile app, deployed via **Docker Compose** (Postgres, gunicorn, whitenoise; optional S3/MinIO media, optional Redis cache). It has evolved from a flat 5-actor MVP into a **B2B2C multi-tenant** platform (Platform → Partner/Branch/Staff → Final Customer, plus Provider organisations) with tenant-isolating selectors and DRF permission classes. The domain covers: public catalog discovery (categories → services → detail with required documents, public-gated pricing, delivery-time display), authenticated customer request submission with document upload and missing-document cycles, an explicit **workflow state machine** (`backend/workflow/rules.py`, 11 order statuses, role-gated transitions, generic-status endpoint locked to a whitelist), internal review + provider execution + final-document delivery, guarded **soft delete** (`SoftDeleteModel` + `AdminDeleteGuardMixin` + delete-password guard + audit), audit logging, in-system notifications, a billing-foundation payment module, reporting, a help-guide/manual subsystem, and public-site CMS (homepage content, theme, advertisements, missing-service requests). Source-of-truth priority: **A1/A2** for the catalog+soft-delete domain, **A3** for tenancy/authorization, **A4/A5** for visual language, **A7** for latest acceptance status, **B1/B2/B3** for everything else.
