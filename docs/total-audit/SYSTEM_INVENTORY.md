# Khalsni system inventory

Taken 2026-10-13 from the working tree on `main`. Counts come from Django's app registry, the URL resolver and directory listings. The endpoint-level inventory is `API_ATTACK_SURFACE.csv` (658 rows, regenerated by `scripts/generate_api_attack_surface.py`).

## 1. Backend (Django 5.2, DRF 3.17, SimpleJWT)

### Apps and models

| App | Models | Purpose |
|---|---|---|
| `core` | none (abstract `SoftDeleteModel`) | Soft delete, delete guard, client address, rate-limit classes, choices |
| `organizations` | Organization, Branch, OrganizationMembership, OrganizationBranding, PartnerServiceConfig | Tenants, membership roles, partner catalog configuration |
| `accounts` | CustomUser, CustomerProfile, SystemSetting, PasswordResetToken | Identity, sign-in, password reset, user administration |
| `services` | ServiceCategory, Service, RequiredDocumentDefinition, ServiceRequiredDocument, ServiceRelation, ServiceProviderAssignment, Address | Catalog, document rules, prerequisites, provider eligibility |
| `orders` | Order, OrderStatusLog, OrderNote, OrderAssignmentHistory, OrderIssue, Rating, MissingDocumentRequest | Order lifecycle and its history |
| `documents` | Document | Uploaded files, review state |
| `workflow` | none | Transition table and actor rules |
| `providers` | ProviderProfile | Provider accounts and work queue |
| `payment` | Payment, Invoice, CommissionRule, ProviderPayout | Manual payment records. No gateway. Invoice, CommissionRule and ProviderPayout have no API. |
| `notifications` | Notification, NotificationTemplate | In-system notifications only |
| `reports` | none | Dashboards and summaries computed from orders |
| `audit` | AuditLog | Audit trail, order timeline endpoint |
| `public_site` | SiteTheme, PublicPageContent, Advertisement, MissingServiceRequest, ContactInquiry | CMS and public forms |
| `help_guides` | HelpGuide, HelpGuideScreenshot, HelpGuideAction, HelpGuideField, HelpGuideService, HelpGuideWorkflow | Contextual help |

## 4. Infrastructure

| Part | Detail |
|---|---|
| Compose services | `db` (postgres:16-alpine), `redis` (redis:7-alpine, added in this audit), `backend` (python:3.12-slim, gunicorn, 2 workers), `frontend` (nginx:1.27-alpine serving the built SPA) |
| Request path (expected) | browser → Coolify Traefik (TLS) → frontend nginx → backend gunicorn. Not verified on the server. |
| Published ports | None in `docker-compose.yml`. `docker-compose.override.yml` (local development) publishes 5432, 8000 and 4173 on loopback. |
| Volumes | `postgres_data`, `backend_media` (mounted read-only into nginx), `backend_static` |
| nginx | SPA with security headers and CSP; `/api/` and `/django-admin/` proxied; `/static/`; media allowlist of five public folders, everything else 404; 50 MB body limit; sign-in rate limit on `/django-admin/login/` |
| Start-up (`backend/entrypoint.sh`) | wait for database → migrate → collectstatic → setup_roles → create_admin → flushexpiredtokens → optional `seed_initial_data` → `seed_service_images` → gunicorn |
| TLS | Terminated by the platform proxy. Django trusts `X-Forwarded-Proto`. |
| Logging | stderr of each container. Django logging configured in this audit. No aggregation, no alerting. |
| Backups | None scheduled. Scripts and runbook added in this audit. |
| CI (`.github/workflows/ci.yml`) | Backend tests (SQLite), backend tests on PostgreSQL (added), dependency audit, frontend lint/test/build/audit, Playwright, mobile type-check, deployment artifacts: settings check, Compose validation, image builds, `nginx -t` (added) |
